# ChatBar

Компактная панель переключения каналов чата для World of Warcraft: золотые
буквы над рядом круглых цветных кнопок, по одной кнопке на каждый доступный
канал. Воспроизводит панель с референсного скриншота.

```
С  К  Ш  Ш  Э  О  Т  О  Т
●  ●  ●  ●  ●  ●  ●  ●  ●
```

## Установка

1. Распакуйте `ChatBar.zip`.
2. Скопируйте папку `ChatBar` в `_retail_/Interface/AddOns/`
   (путь к `Interface/AddOns` зависит от установки клиента).
3. Полностью перезапустите игру и включите ChatBar в списке аддонов.

Итоговая структура:

```
Interface/AddOns/ChatBar/
├── ChatBar.toc
├── ChatBar.lua
└── Textures/
    ├── Orb.blp         сфера, окрашивается цветом канала
    ├── Orb.tga
    ├── OrbGloss.blp    золотой ободок и блик, не окрашивается
    └── OrbGloss.tga
```

`.blp` используется современным клиентом, `.tga` — клиентами до Legion;
аддон обращается к текстуре без расширения, поэтому подходящий файл
выбирается автоматически.

## Команды

| Команда | Действие |
| --- | --- |
| `/chatbar` | список команд |
| `/chatbar lock` | запретить перемещение |
| `/chatbar unlock` | разрешить перемещение |
| `/chatbar reset` | вернуть положение и масштаб по умолчанию |
| `/chatbar scale 1` | масштаб панели (0.5 – 3) |
| `/chatbar hide` | скрыть панель |
| `/chatbar show` | показать панель |

Панель перетаскивается мышью за любую кнопку или за свободное место между
кнопками. Положение, масштаб, блокировка и видимость хранятся в
`ChatBarDB` (SavedVariables, одна запись на аккаунт).

## Как формируется ряд кнопок

Кнопки не зашиты в код: ряд перестраивается из состояния игры.

Всегда: Сказать, Крик, Шепот, Шепот Battle.net, Эмоция.
По условию: Группа, Рейд, Подземелье, Гильдия, Офицерский.
Затем: все номерные каналы из `GetChannelList()` по порядку.

Буква — первый символ локализованного названия канала (`SAY` → «Сказать» → С,
`YELL` → «Крик» → К, канал «Торговля» → Т). Цвет кнопки берётся из
`ChatTypeInfo`, то есть следует настройкам цветов чата игрока; при отсутствии
`ChatTypeInfo` используются стандартные цвета.

Поэтому на одиночном персонаже без гильдии ряд совпадает со скриншотом, а в
группе или гильдии к нему добавляются соответствующие кнопки.

## Размеры

Измерены по скриншоту: кнопка 22 px (видимая сфера ≈ 19 px), шаг между
центрами 26 px, высота букв 15 px, зазор между буквой и кнопкой 3 px,
цвет букв `NORMAL_FONT_COLOR` (1.0, 0.82, 0.0).

## Текстуры

`tools/make_textures.py` восстанавливает текстуры из скриншота. Девять сфер на
скриншоте нарисованы как `A(x,y) · цвет + B(x,y)`, где `A` — нейтральная сфера,
которую окрашивает цвет канала, а `B` — золотой ободок с бликом, который не
окрашивается. Девять известных цветов `ChatTypeInfo` дают переопределённую
систему, из которой `A` и `B` восстанавливаются методом наименьших квадратов
попиксельно и записываются в два файла (BLP2, палитра, 8-битная альфа, полная
цепочка мип-уровней; плюс несжатый 32-битный TGA).

```
python3 tools/make_textures.py        # CHATBAR_REF=<путь к скриншоту>
```

## Проверки

`tools/test_chatbar.lua` загружает аддон в макет WoW API под Lua 5.1 (версия,
на которой работает игра) и прогоняет вход в игру, все команды, нажатия,
наведение и перетаскивание каждой кнопки, а также события смены группы, рейда,
гильдии и списка каналов.

```
python3 - <<'EOF'
from lupa import lua51
L = lua51.LuaRuntime(unpack_returned_tuples=True)
L.eval('function(p, a) return assert(loadfile(p))(a) end')('tools/test_chatbar.lua',
                                                           'ChatBar/ChatBar.lua')
EOF
```

## Версия клиента

`## Interface: 16001, 120100, 120105` — 16001 для WoW: Forever, остальные для
Retail. Клиент выбирает ближайшее значение, не превышающее его собственную
версию интерфейса. Проверить версию своего клиента:

```
/dump select(4, GetBuildInfo())
```

Если число отличается, замените первое значение в `ChatBar.toc`.
